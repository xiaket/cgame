# Emberfield

按照 [spec](doc/spec) 实现的 Godot 4 / GDScript 装备驱动 2D ARPG MVP。无需插件、外部素材或网络连接。

## 运行

用 Godot 4.3+ 导入当前目录的 `project.godot`，按 **F5** 运行主场景。已在 macOS Godot **4.6.3** 进行无界面验证。

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

## 操作

| 输入 | 行为 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准，攻击时辅助吸附前方附近敌人 |
| 按住左键 / Q | Weapon 主动技能 |
| 按住右键 / E | Offhand 主动技能 |
| F | 拾取附近装备 |
| I / Tab | 打开或关闭装备背包，暂停战斗 |
| 点击背包装备 | 装备并替换当前槽位 |
| 点击装备槽位 | 筛选右侧背包，只显示对应槽位的装备 |
| 槽位旁的 × | 卸下，立即失去技能和属性 |
| 背包顶部 ALL EQUIPMENT | 恢复显示全部装备 |
| 悬停装备 | 查看品质、属性和当前装备对比 |
| H / Esc | 帮助 / 暂停；Esc 也可关闭背包 |
| R | 失败后重试当前关卡 |

打开装备界面后，左侧人物面板显示当前/最大生命、装备攻击加成、总攻速、总移速、伤害倍率、两个主动技能的最终单次伤害与攻击频率/CD，以及被动效果。换装或卸装立即更新；悬停属性数值可查看来源和计算说明。

地图从西侧营地向东延伸，包含三处花园战斗区域和连接道路，镜头随人物前进；人物和敌人都受道路边界约束。每次开局和成功进关，随机生成花园尺寸、间距和道路宽度；失败重试保留本关布局。进入各处花园才触发对应战斗，清完三处并击败 Warden 后解锁东侧终点。在终点圆环内连续停留 **2.5 秒**自动进入下一关，离开圆环重置计时，背包或帮助暂停时计时冻结。下一关怪物强度增加 25%，掉落装备等级随关卡增长。

鼠标攻击在光标方向左右各 35° 内辅助选择最近的有效敌人；没有目标时沿光标方向攻击。Q／E 和屏幕攻击按钮自动选敌，优先正面左右各 60° 内的最近目标，再选择周围最近目标，没有目标则沿最后朝向释放。选敌遵守技能射程和地图遮挡，冰环仍以人物为中心。目标显示金色圆环。可以边移动边攻击；暂停或切关后须释放攻击键再重新按下，避免误攻击。不含虚拟摇杆或触屏适配。

Boss 的橙色圆圈会在一秒后造成伤害。击杀恢复基础 4 HP，加上装备回血词缀；终点进关和失败时回收所有地面装备，保留装备继续挑战。每次启动游戏都从第一关、140 基础生命、四个空装备槽和空背包开始，不读写存档。旧版本的存档不会被载入，无需手动删除。同一次运行内，终点进关或失败重试仍保留装备。

## Build 与装备

四个槽位均由装备提供技能：Weapon / Offhand 主动，Helmet / Necklace 被动。出生点放置 Iron Blade 和 Ember Orb，按 F 拾取、I 打开背包并手动装备；装备第一个主动技能后，向东走到第一处花园才开始刷怪。其余装备通过掉落获得。两个主动槽位对等，支持双 Basic、Basic + Power、双 Power；双 Power 同时冷却时无法攻击。

- **Cleave + Frost Nova**：近身扫击清群，冰环减速争取走位空间。
- **Fireball + Frost Nova**：远程爆炸加冰环控场，在两次爆发间走位。
- **Slash**：高频单体近战；**Cleave**：较低单体伤害，命中前方所有目标。
- **Toughness**：增加 65 最大 HP；重复装备不叠加同名被动。
- **Bloodlust**：击杀后 4 秒内伤害提升 40%，再击杀刷新持续时间。

普通敌人 60% 掉落装备，Boss 必掉黄色 Rare。白色 Common：2 主词条、0 副词条；蓝色 Magic：2 主词条、1 副词条；黄色 Rare：3 主词条、1 副词条。装备固定技能占第一个主词条，其余主词条随机且不重复；没有模板隐藏属性。同一件装备只在生成时掷骰，拾取、查看、换装不会重掷。等级显示为 Lv.，并非强化次数。

词缀分类遵循 `doc/affixes`。当前主词缀池：物理攻击、法术攻击、护甲、魔抗、最大生命、指定技能伤害、冷却缩减、附加物理／法术伤害。副词缀池：精英增伤／减伤、移速、拾取范围、生命恢复、击杀回血、近战／远程减伤。魔法值、魔耗、药水、金币、视野等需对应系统后再加入；技能符文、传奇装备、传奇宝石与任务奖励的专属效果不混入随机装备池。当前 Boss 视为精英。

白色的词缀范围定义在 `scripts/data/affix_catalog.gd`，蓝色数值乘 1.25，黄色乘 1.5；物品等级每级为数值型主词缀增加 16%，百分比及副词缀不随等级扩大。物理攻击仅加成 Slash / Cleave，法术攻击仅加成 Fireball / Frost Nova；附加伤害作用于所有主动技能。最终单次伤害为 `[(技能基础 + 对应攻击) × (1 + 指定技能增伤) + 附加物理 + 附加法术] × 嗜血增益 × 精英增伤`，精英增伤仅对 Boss 生效。火球在发射时记录伤害与精英增伤，飞行中换装不会改变它。

近战和 Boss 攻击为物理伤害，敌方远程弹为法术伤害；护甲／魔抗减伤公式为 `100 / (100 + 防御)`，再乘攻击距离类别和精英减伤。冷却缩减上限 40%，近战／远程减伤各上限 60%，精英减伤上限 35%。Basic 固定为每秒 2.4 次；Power 冷却受冷却缩减影响。冷却绑定槽位，换装不会绕过或改写正在进行的冷却。换生命装备不会治疗；生命恢复按游戏内时间生效，暂停时停止。击杀回血为基础 4 点加装备词缀。

## 结构

| 位置 | 职责 |
| --- | --- |
| `data/abilities/*.tres` | 六种独立技能定义 |
| `data/items/*.tres` | 十二种装备模板，引用技能资源 |
| `data/ashen_garden.tres` | 波次、远程怪比例、Boss 波次和强度成长 |
| `scripts/data/level_definition.gd` | 地图道路区域、出生点、战斗触发点及终点的默认配置 |
| `scripts/data/` | Resource 类型、装备实例和目录 |
| `scripts/actors/` | 角色属性、移动、伤害；近战/远程/Boss AI |
| `scripts/systems/ability_system.gd` | 与具体装备分离的可复用技能执行及冷却 |
| `scripts/systems/combat_events.gd` | 伤害、死亡、换装、技能、通关事件 |
| `scripts/systems/journey_map.gd` | 道路边界、移动碰撞和敌人寻路 |
| `scripts/systems/` | 装备管理、品质掉落 |
| `scripts/game.gd` | 关卡生命周期、投射物、拾取及原生 Godot UI |

全部图形由 Godot 绘制，占位角色、地面、掉落光束、技能特效、飘字与 Boss 预警不依赖贴图。

## 验证

随机地图与辅助瞄准新增 15 项检查，包含 100 个种子的地图连通、出生位置、确定性、共享模板及掉落随机序列隔离，以及瞄准角度、射程、遮挡、暂停和重试行为。两套 Build 分别在 3 个地图种子上完成通关，共 6 次；与原有检查合计 155 项通过。图形界面操作手感仍需人工试玩。

首次使用命令行测试前，先让编辑器扫描并注册全局类：

```bash
GODOT=/Applications/Godot.app/Contents/MacOS/Godot
"$GODOT" --headless --path . --editor --quit
"$GODOT" --headless --path . --script tests/integration.gd
"$GODOT" --headless --path . --script tests/affixes.gd
"$GODOT" --headless --path . --script tests/journey.gd
"$GODOT" --headless --path . --script tests/aim_maps.gd
"$GODOT" --headless --path . --script tests/build_simulation.gd
```

测试应使用独立的用户目录；集成测试会临时写入旧版存档以验证它不会被载入，并在结束时恢复原文件。在受限环境可在上述命令前加 `HOME=/private/tmp/cgame-test-home`。集成测试覆盖换装、卸装、六种技能、双 Basic / 双 Power、冷却、被动事件、减速、投射物、掉落、拾取、三波通关、重开、失败、空装备开局、手动拾取起步和忽略旧存档。Build 模拟显式配置未强化的装备，固定时间步推进真实 AI、投射物和技能，验证近战控场与远程爆发两种组合均能打通第一轮。

本次验证：70 项集成检查、29 项词缀检查和 41 项地图／背包筛选检查通过。覆盖道路连通和边界、敌人穿过连接道路、镜头跟随、战斗触发、终点暂停／重置／自动进关、所有槽位筛选、筛选后正确装备及卸装，以及原有词缀和战斗回归。两个 Build 均沿地图推进、击败全部 28 个敌人，并通过终点自动进入第二关。测试也检查了背包和 HUD 的布局边界。受运行环境限制，未完成人工画面与鼠标手感检查；需在本机 Godot 中进一步试玩。
