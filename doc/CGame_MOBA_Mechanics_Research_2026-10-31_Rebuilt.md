**本次扩充阅读路线**：建议先读 **第十三章（M01–M24 候选机制与 CGame 协同）**；按来源深挖时，再看 **第九章（LoL 173 英雄）→第十章（LoL 204 物品）→第十一章（王者 133 名称/形态）→第十二章（王者 120 物品）**。前三章原始 Dota 研究和第 4–8 章精选案例均保留，便于比较。

## 一、分析口径

不以英雄职业或物品价格分组，而以「作用于战斗规则的变化」分组：

1. **动作顺序**：施法→普攻、连击计数、先标记再引爆。
2. **资源交换**：HP↔Mana、伤害↔恢复、承伤↔输出、魔法↔护盾。
3. **时间规则**：延迟结算、时间回溯、冷却返还、保命窗口。
4. **命中结构**：按命中次数结算、方向判定、目标间分配伤害。
5. **位置与环境**：预放锚点、移动蓄势、地形触发、领域约束。
6. **目标条件**：高血/低血/缺魔、精英/普通怪、是否被控制。
7. **模式切换**：武器形态、技能阶段、达到阈值变化。
8. **行为经济**：击杀回资源、指定目标的额外报酬、获得怪物能力。

**与已讨论的 CGame 规则保持一致**：不引入经验值词缀；普通装备暴击/暴伤暂不引入；穿透优先不可堆叠的传奇特效；原来被排除的格挡、吸血、击中回复、普通掉率词缀等不因此恢复。上述条目中的来源机制只是“参考”，不等于建议直接加入。

## 二、跨三款游戏最值得借鉴的机制

| 候选机制 | 游戏实例 | 在 CGame 的设计形式 | 主要收益 | 风险/成本 | 建议 |
|---|---|---|---|---|---|
| **施法强化下次普攻** | LoL Trinity Force、王者宗师之力 | 传奇武器或技能符文：技能后下一击改变效果 | 真正为攻速与施法频率创造配合 | 触发频率与普攻取消问题 | **优先** |
| **普攻缩短某技能剩余冷却** | LoL Navori Flickerblade | 传奇：连续普攻缩减指定技能CD，设置内部冷却 | 攻速成为技能循环核心而非孤立乘区 | CD 循环失控 | **优先，需总门槛** |
| **第 N 次攻击触发效果** | Dota Slardar、LoL Jhin | 技能符文/传奇宝石：第3/4次攻击产生独立效果 | 无需暴击词缀也有攻击节奏差异 | 多段攻击如何计数 | **优先** |
| **施法次数决定下一击模式** | 王者云缨 | 技能符文：1/2/3 次施法使下次普攻效果不同 | 把技能顺序变成决策 | 控制复杂度 | **优先** |
| **被打的伤害延迟结算，击杀可取消债务** | LoL Death's Dance | 传奇装备：30%承伤改为数秒DOT，期限内击杀可免剩余 | 进攻与生存互换，产生紧张窗口 | 伤害事件与死亡边界处理 | **优先** |
| **魔法值承担生命伤害** | Dota Medusa、王者嫦娥 | 传奇：部分扣血改为扣魔 | 最大魔法/回魔拥有生存价值 | 资源循环无限续航 | **优先** |
| **消耗生命来换魔法** | Dota Soul Ring、Phoenix/Huskar | 传奇/技能：扣血回魔 | 资源交换产生可选 Build | 滥用回血循环 | **优先** |
| **把收到伤害的次数变成反击** | Dota Axe、Bristleback、王者极寒风暴 | 传奇：每承受 N 次伤害，下一次释放反击 | 防御词缀可间接创造输出 | 需要防多怪群殴爆炸 | **优先** |
| **只屏蔽固定次数的伤害，不按数值结算** | Dota Templar Assassin | 传奇宝石：每 X 秒挡 1 次直接伤害 | 对快慢攻击怪不同价值 | 与 DOT 相互作用 | 中高 |
| **只强化被标记的目标** | 王者露娜、LoL Cassiopeia | 技能符文：标记之后另一技能触发额外效果/刷新 | 技能循环明确，不直接堆伤害 | 标记 UI / 目标切换 | **优先** |
| **低生命处决，不用百分比增伤词缀** | Dota Ancient Apparition、LoL Pyke | 传奇：若目标血量低于固定比例则触发终结 | 清晰的“少一下”体验 | Boss 特殊规则 | 中高 |
| **技能构型改变而非增伤** | Dota Kez、Invoker；LoL Hwei | 某些技能等级阈值、装备传奇特效 | 高 Build 识别度 | 技能组合爆炸 | 中高 |
| **技能范围起点由场上锚点决定** | LoL Orianna、王者公孙离 | 技能符文：投放锚点，下一招从锚点发出 | 多样空间决策 | 动作操作负担 | 中高 |
| **站位影响防御** | Dota Bristleback、Mars | 传奇胸甲：正面/背面效果有区别 | 走位成为 EHP 的一部分 | 2D 转向准确度 | 中 |
| **击杀具名怪取得暂时能力** | Dota Doom、LoL Viego | 特殊关卡或传奇：短时间获得具名怪技能 | 精英怪的玩法价值不止掉落 | 技能兼容与制作成本 | 中 |
| **生命值产生攻击收益** | Dota Centaur、LoL Heartsteel、王者血魔之怒 | 传奇：最大生命/承伤事件驱动攻击 | 给防御 Build 真正输出路径 | 防高血量万能最优 | 中 |
| **移动产生攻击能量** | Dota Spirit Breaker、王者马超、LoL Dead Man's Plate | 传奇：移动一段距离后下一击强化 | 移速不只用于跑图 | 刷怪刻意绕圈 | 中 |
| **特殊资源对应两种用途** | Dota Outworld Devourer、LoL Manamune | 传奇：魔法用于施法，也可为伤害储备 | 最大魔法值得捡、魔法恢复有价值 | 攻防都转换导致叠乘 | 中 |
| **范围单位链接分摊伤害** | Dota Warlock Fatal Bonds、Grimstroke | 传奇：标记两名敌人共享伤害的固定比例 | 单体/群体伤害间的新桥梁 | 链式递归、CPU计算 | 低优先级，防递归 |
| **目标状态影响伤害而非随机暴击** | Dota Anti-Mage 对缺魔目标；王者低血条件装备 | 传奇：针对缺魔/低血固定触发 | 突破暴击体系 | 对无魔敌人失效 | 中 |
| **技能/装备效果自动触发但有明确代价** | LoL K'Sante、Dota Armlet | 传奇：开启强化形态但失去防御或持续扣血 | 强大但不是白送的机制 | 玩家需能理解代价 | **优先** |
| **攻击标记累积到阈值，获得非数值进化** | LoL Kai'Sa、Kha'Zix | 技能等级/稀有词缀满足门槛后行为进化 | 让技能 +N 成为强需求 | 防止反向形成唯一门槛 | 中 |

**额外重要的反例**：Dota Refresher Orb、LoL Navori 体现了冷却重置的潜力，也暴露了无限技能循环的风险。对 CGame 更安全的版本是**指定技能、限定触发、每次按固定秒数减 CD**，而不是多个“剩余冷却百分比降低”层层叠加。Dota 中大量主动装备也值得研究，但不意味着 CGame 要给每件传奇新增一个按键。

**LoL 最重要的机制性启发**：

- **攻速有可能是“冷却词缀”**，而不只是 DPS 倍率。Navori Flickerblade 通过普通攻击减少剩余技能 CD。若 CGame 想保留攻速，类似的机制能给它独立 Build 身份。
- **技能与普攻交替是明确可读的循环**。Trinity Force、Dusk and Dawn、Lich Bane 均体现了 Spellblade 结构，但后者重复触发命中效果需要防递归。
- **延迟伤害 + 击杀取消余债**（Death's Dance）比纯减伤更贴合刷怪游戏：以更快击杀换生存，不会让防御成为唯一标准答案。

**王者最重要的机制性启发**：

- 云缨：**技能使用次数决定下一次普攻属于哪一档招式**。这让攻速、冷却缩减、魔法消耗与“普攻选择”发生自然协同。
- 姬小满：不同技能顺序组合出不同效果。适合 CGame 的轻量形式是“前一个技能的标签影响下一个技能”，不一定复制全套连招。
- 露娜：技能附加标记，另一技能命中标记后刷新或返还冷却；这是直接把攻击速度/施法频率拉入同一个 Build 循环的典型。
- 宗师之力/冰痕之握/巫术法杖：三者同属于 Spellblade 范式，但后续效果分别偏伤害、控制、法术复合。**同一传奇底层模板可以衍生多个有取舍的掉落。**
- 英雄专属装备的意义在于：它们**改变技能表达方式**，说明传奇不一定要增加新技能，更可以替换原技能的行为。

## 六、落到 CGame 时的技术及平衡边界

| 设计问题 | 建议边界 |
|---|---|
| 触发事件爆炸 | 将 OnHit、OnKill、OnCast、OnTakeDamage 的调用链与直接伤害/继发伤害区分。大部分特效只允许由主事件触发，不允许自触发递归 |
| 攻击速度的价值 | 如果保留，应至少提供一种独特循环（例如普攻使技能 CD 减少 0.25 秒），而非只有增伤乘区 |
| 冷却缩减 | 白/蓝/黄/天然传奇仍按部位随机；传奇的「返还冷却」是另一类特殊机制。明确是否遵守 CDR 上限及触发内部冷却 |
| 技能伤害与伤害类型 | 物理/法术为两个基础通道；伤害转换属于传奇“开关”而非普通可堆词缀；避免连锁转换顺序不清 |
| Boss 与普通怪 | OnKill 很强但 Boss 上经常无效；可通过具名怪的小怪阶段、受击累积、终结阶段提供替代用途，但不要无条件补偿 |
| EHP 模型 | Mana Shield、延迟承伤、次数屏障无法以静态 EHP 完全表达；应采用战斗场景仿真，另记录 burst survival 和 sustained survival |
| 2D 动作手感 | 方向减伤/移动蓄力机制依赖明确的朝向、移动阈值和反馈；先在 POC 中用极简版本验证 |
| CGame 的小数值目标 | 条件增伤尽量用固定次数、固定阈值或单一加成桶；避免某条传奇给多个互乘伤害乘区 |
| 普通装备三主一副 | 机制型传奇仍占 1 个主词缀；宝石提供升级的触发机制，不能绕过该资源交换约束 |
| 性能负荷 | 避免所有伤害事件都扫描周围所有单位；范围伤害、扩散与共享伤害仅对明确选择的技能/传奇建立索引和事件预算 |

## 七、下一步筛选建议（仍未纳入设计文档）

如果只挑 5 个做 CGame POC 机制实验，优先：

1. **施法后强化下一次普攻**：验证攻速与 CDR 对循环的真实作用。
2. **第 N 次普攻触发固定效果**：无需引入暴击词缀，让攻击节奏有可感知变化。
3. **使用生命换魔法 + 魔法盾承伤**：验证资源型 Build 的进攻/防御取舍。
4. **承伤延迟结算，击杀可抵消部分债务**：验证生存型与高风险输出型是否同样可玩。
5. **指定目标标记→另一个技能引爆或返还 CD**：验证技能符文是否能创造 Build 而非仅增加伤害。

### 9.1 从 LoL 英雄技能提炼出的新命题

| 机制命题 | 代表英雄 | 为 CGame 提供的设计空间 | 风险 |

### 9.2 重点技能链（按事件拆开，而非照抄英雄技能）

1. **Xayah**：普攻/技能把飞羽留在地上 → 再施技能收回飞羽 → 路径上敌人遭多次命中并可能受控。CGame 可以设计「箭矢在场时间 +X%」主词缀与「回收飞羽时使其转成另一种伤害」传奇，不需新增额外攻击键。
2. **Ezreal / Master Yi**：命中动作抵扣剩余技能冷却。配合攻速，形成施法与攻击交替循环。实现时建议按 `attack_event_id` 只抵扣一次，排除同一次攻击弹射重复计数。
3. **Katarina / Irelia**：击杀指定目标后，恢复一次位移或技能。角色越强则清怪越顺，但 Boss 战需要一个不依赖击杀的替代条件（例如每命中精英 N 次）。
4. **Gnar / Rumble**：资源达到阈值后行为改变；继续堆某属性可能引入负面效果。这比「能量越多输出越高」更有取舍。
5. **Qiyana / Poppy / Taliyah**：地形不只是障碍，也可作为技能材料、控制触发器或技能疲劳区。若 CGame 地图为随机生成，需保证地形可用性。
6. **Jhin / Samira**：固定第四击或不同动作类型的积累，让攻速不简单等于攻击次数；可给单一技能专属暴击逻辑而非装备暴击词缀。
7. **Renata / Ekko / Zilean**：濒死、延迟结算、回溯/复活不是额外护甲，而是改变时间规则，适合稀有传奇，但必须明确 DOT、Boss 与不可逆事件的处理。
8. **Azir / Orianna / Heimerdinger**：施法起点/攻击来源与角色本人分开，有价值也有明显 AI、碰撞与视效成本。

### 12.1 《王者荣耀》装备系统对 CGame 的启示

- **宗师之力 / 巫术法杖 / 冰痕之握**：同一「技能后强化普攻」范式，分别映射输出、法术输出、防御+控制。CGame 可把同一原型作为不同部位的传奇，不必制作完全不同的代码机制。
- **名刀·司命 / 辉月 / 贤者的庇护**：短暂免死、主动停滞、复活都解决了生存问题，但操作与代价不同。CGame 可限制每件装备只提供一个关键保命窗口，以免触发链永动。
- **末世 / 痛苦面具 / 破军**：分别偏向高血目标、持续伤害、低血目标；同一个 DPS 在不同敌群有不同价值。CGame 可优先用特定传奇而非新增普适百分比词缀。
- **极寒风暴 / 暴烈之甲 / 反伤刺甲**：承伤反馈可产生控场、移动或输出，但触发间隔与防多怪并发要明确。
- **逐日之弓 / 纯净苍穹 / 极影·奔狼**：主动技能能够有效制造差异，不过 CGame 需要控制额外装备技能按键数量。
- **专属装备**：作为「特定英雄/技能」的强绑定机制，在 CGame 中不宜大范围照搬，否则容易回到每技能的固定毕业装答案。

### 13.1 与已经确认的 CGame 决定保持隔离

- **不推荐恢复**：普通词缀穿透、格挡、吸血、击中回复、经验、装备掉率等。
- **可以把机制搬到正确容器**：穿透→特定传奇；连续命中叠伤→可升级传奇宝石；位移/标记连击→技能符文；转伤/延迟伤→传奇装备。
- **攻速/施法速度仍然未拍板**：这轮研究证明它们可以成为特定 Build 的核心，但并不说明必须作为常见随机主词缀。是否加入仍需对技能循环进行数值测试。
- **基础伤害仍分物理/法术**；具体防御公式和副词缀数值尚未定案。任何来源的 PvP 穿透、真实伤害、百分比伤害都不能未经调整直接移植。

### 14.3 若要严格满足“所有技能逐招核验”，还需要的步骤

真正的逐技能审计至少应有**每条技能一条记录**，含 `source_version / champion / skill_slot / active_or_passive / trigger / effect / stack_rule / target_rule / cooldown_rule / resource_rule / CGame_category / verification`。当前文件是**完整英雄与装备对象名单 + 一轮机制审查**；它不是逐条技能 tooltip 数据库。要完成该下一层审计，需可靠抓取 Riot 单英雄 JSON 与腾讯官方英雄技能详情，并逐条检验模式、版本、复杂形态。由于本轮运行环境无法直接下载这些动态 JSON，文档明确保留此差距，不把未核实的数据填成“已完成”。

### 14.4 CGame 的后续讨论应按什么顺序

1. **先挑机制**：对第十三章 M01–M24 标记「值得做 / 暂缓 / 排除」。
2. **再画技能循环**：找 3–5 组典型 Build（攻速、CD、最大魔法、持续范围技能），验证每个传奇是否有真正的取舍。
3. **最后定词缀池**：只有需要这些循环的属性才进入主、副词缀池；其余保持传奇/符文/宝石，不盲目扩大随机池。
